CONOCIMIENTO Y TRANSPARENCIA

Reglas y metodología

Los hallazgos son hipótesis generadas mediante correlación temporal. El modelo ML opcional se encuentra en el proyecto Python, no en esta demo estática.

La demo HTML muestra resultados precalculados para facilitar la revisión del portfolio sin instalar dependencias. Para analizar nuevos registros, ejecutar la interfaz streamlit run app.py o el CLI del repositorio. Sin escaneos ni conexión a servicios de terceros. AUTH-005 (accesos nocturnos) está desactivada por defecto, por eso no genera alertas en esta demo.
